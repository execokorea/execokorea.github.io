Technical Briefing

엑세코는 1MW 이하 소규모 태양광 발전소(또는 관리 업체)가 KPX 전력 입찰 시장에 참여해 (현) 한전 직거래보다 많은 보상금 수익을 얻을 수 있게 하는 VPP(가상발전소) 플랫폼입니다.

엑세코 개발 배경
신재생 에너지의 선두이자 전력 특구 제주는 최근 15분 단위 계통 운영까지 실현하며 실시간 전력 시장을 이끌고 있습니다. 그러나 10년간 이어진 정부의 태양광 지원 정책으로 늘어난 숨은 태양광(Behind-the-Meter, BTM)으로, 갑작스러운 발전소 중단과 대규모 정전이 자주 발생하고 있습니다. 엑세코는 숨은 태양광의 전력 시장 참여와 계통 안정화를 위해 기상・전력・관광 분야 25만개 데이터로 트레이닝한 예측 모델과 VPP플랫폼을 개발했습니다.

예측 모델

수집한 CSV를 가공(피처 엔지니어링)하고, 시간 순서를 지켜 학습·검증을 나눈 뒤 LSTM 계열 딥러닝 모델을 학습합니다.
학습은 Apple MPS(Apple Silicon GPU 가속)에서 수행해, GPU 서버없이 로컬에서 끝냈습니다.

*AR : Autoregressive Model, 자기 회귀 모델
*GBM : Gradient Boosting Machine, 머신 러닝 모델-지도 학습
*LSTM : Long Short-Term Memory, 딥러닝 모델
*MAPE : 예측 오차가 실제값에서 차지하는 비율을 백분율(%)로 나타낸 평균 오차. 낮을수록 좋음
*R² : 모델이 데이터의 전체 분산(변동성)을 얼마나 잘 설명하는지 나타내는 비율. 1에 가까울수록 좋음

모델 학습

  1. 1. INPUT원본 데이터SMP·기상·입도객·발전소
  2. 2. FEATURES피처 엔지니어링시간·요일 sin/cos, 지연값, 이동평균, 불쾌지수, 체류인구 추정
  3. 3. SCALING스케일링학습 구간에서만 기준 계산 (누수 방지*)
  4. 4. TRAIN모델 학습PyTorch LSTM · Apple MPS
    seed 42 · EarlyStopping
    과거 168시간 → 다음 수요
  5. 5. ARTIFACTS학습 산출물models/*.pt (가중치)
    scaler.npz · metrics.json
  6. 6. SERVE추론 서빙FastAPI → JSON
    SMP 화면 · 웹 v5~v7

공통 학습 설정: 시간 순서로 학습·검증 분할, 스케일링 기준은 학습 구간에서만 계산, seed 42, EarlyStopping, Apple MPS(로컬 GPU)에서 학습.

누수 방지* 시험의 정답을 미리 보지 않도록 검증 데이터를 학습에서 분리하는 것. 시계열은 과거에서 미래 순서로만 나누고, 정규화 기준값도 학습 데이터에서만 계산합니다.

검증 상태와 한계

연구 프로젝트로서 된 것과 아직 안 된 것을 구분해 둡니다.

상태내용
구현·재검증 완료데이터 수집 파이프라인, 수요 예측 모델(오차 약 6%), SMP 누수 수정 후 재학습, walk-forward 검증 도입
한계SMP 예측 정확도는 수요보다 낮음. 데이터 수집에 실패하면 일부 화면이 데모 값으로 대체 표시되며, 실측과 모의를 구분해 표기하는 작업이 후속 과제입니다.

용어 사전

용어설명
SMP (계통한계가격)전력 도매시장에서 매시 결정되는 1kWh당 거래 가격. 수요가 공급능력에 근접하면 급등합니다.
EPSIS / KPX한국전력거래소(KPX)와 그 전력 통계 시스템(EPSIS). 전력 시장 데이터의 공식 원천입니다.
ASOS기상청 종관기상관측망. 기온·습도·풍속 등을 정시 관측합니다.
THI (불쾌지수)기온과 습도를 조합한 지수. 여름 에어컨 사용과 전력수요가 강하게 연결됩니다.
LSTM시간 흐름이 있는 데이터를 다루는 딥러닝 신경망. 최근 168시간의 패턴으로 다음 시간을 예측합니다.
MAPE / R²MAPE는 평균 오차(%)로 낮을수록 좋고, R²는 설명력으로 1에 가까울수록 좋습니다 (0 이하는 추측만 못함).
누수 (data leakage)검증용 정보가 학습에 새어 들어가 성능이 실제보다 과대평가되는 결함입니다.
walk-forward 검증기간을 한 칸씩 옮겨가며 반복 검증하는 방식으로, 시계열 모델의 실전 성능을 더 믿을 수 있게 측정합니다.
MPSApple Silicon의 GPU 가속 인터페이스. CUDA 대신 이것으로 로컬 학습했습니다.
Tailscale Funnel내 기기를 공인 HTTPS 주소로 공개해주는 터널링 서비스입니다.
